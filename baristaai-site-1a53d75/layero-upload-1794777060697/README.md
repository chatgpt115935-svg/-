# BaristaAI — школьный проект с двумя режимами

В проекте есть два режима работы:

1. **Настоящий ИИ** — сервер Node.js отправляет запросы в GigaChat. Секретный ключ хранится только в переменных окружения сервера и не попадает в браузер.
2. **Оффлайн-демонстрация** — локальный разбор простых заказов, набор узнаваемых рисунков и генерация геометрического узора. Она не обращается к API и может показать анимацию даже без интернета. Это демонстрационный алгоритм, а не полноценная нейросеть.

Если библиотека Three.js загрузилась, интерфейс использует исходную 3D-модель. Если интернет отсутствует и библиотека не загружена, включается автономная иллюстрированная 2.5D-сцена. Текстовый ввод работает локально. Распознавание речи в браузере может требовать сетевого сервиса браузера, поэтому для полностью оффлайн-защиты лучше заранее проверить его или пользоваться полем ввода.

## Быстрая автономная демонстрация без интернета

Откройте файл `offline-demo.html` двойным щелчком в браузере. Он не загружает Three.js, шрифты или другие внешние библиотеки: при отсутствии сети показывает автономную иллюстрированную сцену, локальный разбор заказа и анимацию. В выпадающем списке уже выбран оффлайн-режим.

Для полноценного режима с сервером используйте инструкции ниже.

## Локальный запуск

Нужен Node.js 20 или новее.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Запустите:

   ```bash
   npm start
   ```

4. Откройте `http://localhost:3000`.

Без файла `.env` настоящий ИИ не подключится, но оффлайн-режим будет работать. Для автономной демонстрации выберите «Что происходит внутри» → «Оффлайн-демонстрация».

## Подключение настоящего ИИ через GigaChat

1. Создайте проект GigaChat API в кабинете разработчика Сбера и получите ключ авторизации.
2. Скопируйте `.env.example` в `.env`.
3. Вставьте ключ авторизации в `GIGACHAT_CREDENTIALS` без кавычек:

   ```env
   GIGACHAT_CREDENTIALS=ВАШ_КЛЮЧ_АВТОРИЗАЦИИ
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   GIGACHAT_MODEL=GigaChat-3-Ultra
   ```

4. Перезапустите `npm start` и нажмите «Проверить ИИ-сервер».

Сервер получает короткоживущий OAuth-токен, кеширует его до истечения срока и обращается к `https://api.giga.chat/v1/chat/completions`. Не помещайте ключ в HTML, JavaScript, GitHub или скриншоты. `.env` уже добавлен в `.gitignore`.

**Важно о бесплатном доступе:** модель GigaChat-3-Ultra описывалась в документации как доступная физлицам во Freemium-режиме, но условия для новых клиентов и покупка токенов менялись. Перед регистрацией проверьте текущие условия в официальном кабинете. Бесплатный доступ не гарантируется этим проектом.

Официальные страницы:
- API и авторизация: https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api
- Быстрый старт физлиц: https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart
- GigaChat 3 Ultra: https://developers.sber.ru/docs/ru/gigachat/models/gigachat-3-ultra

Если сервер выдаёт TLS/certificate error, проверьте требования Сбера к сертификатам НУЦ Минцифры. Не отключайте проверку TLS-сертификатов.

## Публикация сайта в России через Layero

Для школьной демонстрации можно использовать российский хостинг Layero: он описывает размещение сайтов на серверах в России и поддержку Node runtime.

1. Установите Node.js 20+ на компьютер.
2. Войдите в аккаунт Layero и откройте терминал в папке проекта.
3. Выполните:

   ```bash
   npx layero@latest login
   npx layero@latest deploy
   ```

4. В панели проекта откройте **Project → Environment Variables** и добавьте:
   - `GIGACHAT_CREDENTIALS` — ключ авторизации;
   - `GIGACHAT_SCOPE` — `GIGACHAT_API_PERS`;
   - `GIGACHAT_MODEL` — `GigaChat-3-Ultra`.
5. Перезапустите/передеплойте приложение, если панель попросит это сделать, и проверьте `/api/health` и тестовый заказ.

В проект уже добавлен `layero.json` с Node runtime и командой `node server.js`. Условия бесплатного runtime, лимиты и доступность внешнего API надо проверить в кабинете хостинга до защиты.

Документация Layero:
- Быстрый старт: https://docs.layero.ru/en/getting-started/quickstart
- Runtime Node: https://docs.layero.ru/runtime/overview/
- Переменные окружения: https://docs.layero.ru/deploys/env-vars/

## GitHub: для хранения кода, не для запуска сервера

Можно загрузить этот проект в приватный или публичный GitHub-репозиторий, но GitHub Pages запускает только статические файлы. Он не запускает `server.js` и не может безопасно хранить серверный ключ. Для работающего ИИ подключайте репозиторий к платформе с Node runtime (например, Layero) либо запускайте сервер локально.

Перед `git push` проверьте, что `.env` не попал в репозиторий:

```bash
git status --short
```

В репозитории должен быть `.env.example`, но не `.env`.

## Проверка перед школьной защитой

1. За день до защиты проверьте живой ИИ через опубликованный адрес.
2. Проверьте пример: «Большой латте с рисунком посудомоечной машины».
3. Проверьте уточнение: «Сделай средний» или «Добавь рисунок кота».
4. Отключите интернет на компьютере и откройте локальный проект через `npm start`.
5. Выберите «Оффлайн-демонстрация» и запустите готовый сценарий.
6. Возьмите с собой архив проекта и локально установленный Node.js, чтобы не зависеть от доступности сайта.

## Ограничения

- Оффлайн-режим — локальный алгоритм с ограниченным пониманием текста, а не нейросеть. Неизвестный объект отображается как узор, созданный из текста запроса.
- В полностью оффлайн-режиме голосовое распознавание может быть недоступно в зависимости от браузера; текстовый ввод остаётся доступен.
- Ограничитель частоты запросов в сервере предназначен для небольшой школьной демонстрации, а не для публичного сервиса с большой аудиторией.
- API-ключ не добавляйте в `.env.example`, `public/`, Git или HTML.
